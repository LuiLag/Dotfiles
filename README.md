# 🐱 Dotfiles — Arch Linux + Hyprland (Material 3)

Entorno personalizado en **Arch Linux** con **Hyprland** (configurado en Lua), colores dinámicos **Material Design 3** generados con `matugen` y gestión de paquetes mediante **GNU Stow**.

## ✨ Características Principales
- **Escritorios por Actividad:** 5 espacios de trabajo con iconos en Waybar (`Programar`, `Navegar`, `Jugar`, `Música`, `Varios`) y cambio automático de wallpaper independiente por monitor (`DP-3` y `HDMI-A-1`).
- **Colores Dinámicos (`matugen`):** Sincronización automática de paleta en Kitty, Waybar, Rofi, SwayNC y Hyprlock.
- **Centro de Control (`Super + N`):** Panel lateral SwayNC acompañado de widget flotante con reloj apilado y clima en vivo.
- **Galería Visual de Fondos (`Super + W`):** Selector Rofi en cuadrícula con miniaturas redondeadas.
- **Terminal & Editor:** Kitty transparente con Fastfetch personalizado, Starship, Yazi y Neovim configurado desde cero en `init.lua`.

## ⌨️ Atajos Esenciales

| Atajo | Acción |
| :--- | :--- |
| `Super + Q` | Abrir terminal Kitty |
| `Super + C` | Cerrar ventana activa |
| `Super + Espacio` | Lanzador de aplicaciones (Rofi) |
| `Super + E` | Explorador de archivos (Yazi) |
| `Super + N` | Centro de Control + Reloj y Clima |
| `Super + W` | Galería visual de wallpapers |
| `Super + V` | Historial del portapapeles |
| `Super + Shift + X` | Captura de pantalla por área |
| `Super + L` | Bloquear pantalla (`hyprlock`) |
| `Super + /` | Mostrar chuleta completa de atajos |
